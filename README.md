# 🚀 C Lessons: C Programlama Serüvenim

Bu depo, üniversite öğrenimim boyunca **C Programlama** derslerinde aldığım notları, çözdüğüm laboratuvar örneklerini ve kendimi geliştirmek adına internetten bulup uyguladığım projeleri içermektedir.

## 📂 İçerik ve Konular

Bu depoda aşağıdaki temel ve ileri seviye C konularına dair örnekler bulabilirsiniz:

* **Temel Sözdizimi:** Değişkenler, Veri Tipleri, Operatörler
* **Kontrol Yapıları:** `if-else`, `switch-case`, Döngüler (`for`, `while`, `do-while`)
* **Fonksiyonlar:** Parametre geçişleri, Recursive (Özyinelemeli) fonksiyonlar
* **Diziler (Arrays) & Stringler:** Çok boyutlu diziler ve string manipülasyonları
* **Pointerlar (İşaretçiler):** Bellek adresleme, Pointer aritmetiği (En sevdiğimiz kısım! 🔥)
* **Bellek Yönetimi:** `malloc`, `calloc`, `realloc` ve `free` kullanımı
* **Yapılar (Structs) & Birlikler (Unions):** Kendi veri tiplerimizi oluşturma
* **Dosya İşlemleri:** Dosya okuma/yazma (`fopen`, `fprintf`, `fscanf`)

## 🛠️ Kurulum ve Çalıştırma

Kodları kendi bilgisayarınızda çalıştırmak isterseniz, bir C derleyicisine (GCC gibi) ihtiyacınız olacak.

1.  **Depoyu klonlayın:**
    ```bash
    git clone [https://github.com/arslan468/C_Lessons.git](https://github.com/arslan468/C_Lessons.git)
    cd C_Lessons
    ```

2.  **Bir dosyayı derleyin (Örnek):**
    ```bash
    gcc ornek_dosya.c -o ornek_uygulama
    ```

3.  **Çalıştırın:**
    * Windows için: `ornek_uygulama.exe`
    * Linux/Mac için: `./ornek_uygulama`
